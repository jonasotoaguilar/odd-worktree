## CodeGraph

Run one call to the CodeGraph tool you hold before you search or read code — `fd`, `find`, `rg`, `grep`,
`read` or `cat` — when the task needs structure rather than a lookup: where something lives, who calls it,
what a change reaches. Skip it only for an exact string or a file path you were given. The other tools stay
available after the first call.

The answer is a map, not proof: confirm it in the source, and read a file before editing it.
