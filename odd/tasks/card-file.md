# card-file

One Customize line, renamed from `Card diff`, that styles the `read`, `write` and `edit` tool output the
same way: syntax-highlighted by language and theme, line numbers on the left, a vertical rule, long lines
cut with an ellipsis. Skills and ODD paths keep their own file card and the two never draw one call.
Branch `feat/card-file` (from `feat/card-message`), worktree `odd-worktree-worktrees/card-file`.

## Specs

- S1: "debe estilizar tool read/write/edit output maximizada segun el tema y lenguaje, edit ya tiene uno asi y se activa con "Card diff" ahora ese swricht sera para estilizar esa 3 tools" (`read`, `write` and `edit` are drawn by the one line that `Card diff` is today)
- S2: "la excepcion de ruta skills y odd tiene otro estilo, para que no choquen o itenten pintar a la vez si estan ambos activos" (a skills or ODD path keeps the file card of `Card activity`; the two designs never draw the same call)
- S3: "la tool read y write creo que igual tenian un estilo para los markdown los .md, nose si estaba o era solo skills/odd pero al ser un lenguaje su estilizado fuera de odd/skills iria en este switch" (outside skills and ODD a markdown file is just a language, styled by this switch like any other)
- S4: "revisar consistencia de diseno entre los 3, se vean igual, por ekjemplo el edit se ve las linea a la izquierda y la linea vertical, que todos se vean asi, cosistencia en formato/documento, si es muy larga la linea se cortaba con los "..." para que quede bien las lienas, esto para los 3" (same layout in the three: line numbers on the left, the vertical rule, long lines cut with an ellipsis)
- S5: "cambia el nombre de switch de "Card diff" a otro, piensa en uno mas consistente ahora que sera para las 3 tools" (the line gets a new name that fits the three tools)
- S6: "tal como lo hace comando files" (the look reference is the `/files` preview: highlight by language and theme with a gutter)
