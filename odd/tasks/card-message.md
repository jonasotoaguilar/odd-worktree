# card-message

A `Card message` Off/On switch in Customize > Cards that draws the user prompt and the assistant's
final answer as cards in the configured float/neon style, with the identity prompt gated by it.
Branch `feat/card-message` (from `refactor/no-bridge-naming`), worktree `odd-worktree-worktrees/card-message`.

## Specs

- S1: "una nueva campo en customize "Cards" que sera "Card message" Off/On, si esta On se pinta nuevos y antiguas con este diseno" (the row is literally `Card message`, values Off and On, in the `Cards` page; On paints new AND already-drawn messages)
- S2: "actualmente el diseno depende que este activo activity, ahora lo cambiaremos tanto mensaje de input/respuesta con este diseno de neon/float depende de una nueva campo" (the user prompt card and the assistant card depend ONLY on `Card message`, no longer on `Card activity`; the style is the configured neon or float)
- S3: "la identidad con identity que sirve para el diseno de input deja configurarla igual siempre aunque este desactivado" (`/identity` keeps working whatever `Card message` says)
- S4: "el prompt incrustado es solo si esta indentidad esta seteada y el diseno message esta activo, solo con ambos incrusta a orchestator esa seccion. Ademas el message incrustado sacalo en un .md, los prompts es mejor tenerlos aparte para leer y modificar mas facil, auqnue sea corto, como las reglas de worktree y codegraph." (the identity section is added to the orchestrator prompt only when an identity name is set AND `Card message` is On; its text lives in a `.md` file next to the worktree and codegraph rule files)
- S5: "este diseno de mensaje solo aplica a la respuesta final del turno, no a las intermedias" (the assistant card is drawn only for the final answer of a turn, never for an intermediate message; this must also hold for a resumed session and old sessions)
- S6: "que al igual que el input se vea dentro de un recuadro que siga diseno neon o float (el que este configurado)" and "de color rol mismo que el de checking (en mi tema es rosa creo, el tokyonight)" (same frame as the input card, painted with the theme role the `checking` activity uses)
- S7: "✿ Gentleman · 21:40" (the heading: the mark, the fixed name `Gentleman`, the time it answered; the body stays Pi's own Markdown, only the frame/background is new)
- S8: "cuanto tiempo trabajo y cuantos turnos, o sea, diferencia entre el input anterior y respuesta final. ✿ Gentleman · 21:53 (17 turns · 58m20s)" (the heading carries the number of turns and the elapsed time between the previous user input and this final answer, taken from the session history and not from the session total)
